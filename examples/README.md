# 示例输入与目标输出

本目录提供小说转剧本工具的最小演示样例，用于后续开发章节解析、YAML Schema 校验和端到端转换流程。

## 文件说明

- `novels/three_chapters.txt`：原创三章中文小说样例。
- `outputs/three_chapters_screenplay.yaml`：该小说对应的目标结构化剧本 YAML 样例。

## 样例设计原则

1. 至少包含 3 个章节，满足产品最小输入要求。
2. 包含人物、地点、关键道具、伏笔和回收，便于测试全局一致性。
3. YAML 输出保留 `source_refs`，方便验证场景和章节来源关系。
4. 目标输出是“可继续打磨的剧本初稿”，不声明为最终投拍稿。
